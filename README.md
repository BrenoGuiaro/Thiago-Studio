# Thiago Guiaro Studio — Agenda

Projeto de agendamento desenvolvido com React, Vite e Tailwind CSS.

## Executar localmente

1. Instale o Node.js (versão LTS recomendada).
2. No terminal, entre na pasta do projeto.
3. Execute `npm install`.
4. Execute `npm run dev` e abra o endereço informado pelo Vite.

A identidade visual foi atualizada para a paleta monocromática da marca, com a logo aplicada na página pública, na área administrativa, na tela de login e como ícone da aba do navegador.
